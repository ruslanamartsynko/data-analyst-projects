# Project 01 — Customer Segmentation (RFM + K-Means)

**Мета:** сегментувати клієнтів інтернет-магазину на основі поведінки, щоб запропонувати стратегії комунікації.

**Дані:** `data/transactions.csv` — синтетичні замовлення 1 200 вигаданих клієнтів за 12 місяців. Згенеровані `generate_data.py`; це не реальні продажі.

**Метод:** RFM: Recency = днів з останнього замовлення до 2026-10-01; Frequency = кількість різних замовлень; Monetary = сума витрат. Для кластеризації застосовано `log1p`, StandardScaler, K-Means (`k=3`). Номери кластерів не є назвою класу/порядком цінності.

**Файли:** `analyze.py`, `sql/rfm_postgresql.sql`, `outputs/customer_segments.csv`, `outputs/cluster_profiles.csv`, `outputs/clusters.png`.

**Чому це важливо:** RFM перетворює транзакції на поведінкові ознаки; кластери допомагають сформувати гіпотези для CRM, але не доводять причинного впливу кампаній.

**Питання на співбесіді:** Чому логарифмуємо дані? Як вибирати k? Чим K-Means гірший для категоріальних ознак? Як уникнути leakage в майбутніх прогнозах? Як перевірити стабільність кластерів? Яку бізнес-дію пропонуєш для кожної групи?
