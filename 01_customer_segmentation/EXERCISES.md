# Завдання для самостійної роботи

1. Порахуй RFM тільки в SQL; зістав із Python результатом для 10 клієнтів.
2. Порівняй k=2,3,4,5 за silhouette score; перевір, чи мають кластери бізнес-сенс.
3. Перевір, як зміняться сегменти без логарифмування чи стандартизації.
4. Дай змістовні назви кластерам на основі `cluster_profiles.csv`, не покладаючись на номер.
5. Запропонуй для кожного сегмента CRM-гіпотезу та KPI; поясни, чому підвищення KPI не можна приписати сегментації без експерименту.
6. Напиши одну SQL-вибірку із `GROUP BY`, `HAVING` і одну з віконною функцією.
